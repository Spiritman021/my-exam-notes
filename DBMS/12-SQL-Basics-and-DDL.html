Chapter 12

SQL Basics: Command Types and DDL

SQL (Structured Query Language) is the standard language for relational databases. Chapters 10 and 11 were the theory; SQL is what you actually type. This chapter covers the commands that build and change tables, put rows in and take them out, and control who may do what. Chapter 13 covers querying with SELECT.

12.1Introduction to SQL; DDL, DML, DCL, TCL (House on an Empty Plot; Mom's Kitchen)

🎓 Lecture topic (from outline) SQL is declarative: you say what you want, and the DBMS decides how to do it. It's case-insensitive for keywords, and each statement ends with a semicolon. Its commands fall into families:

Analogy: a house on an empty plot

A new database is an empty plot. DDL builds the house: the rooms (tables), their size and layout (columns and types), and the rules (constraints). DML is moving in and living there: putting furniture in, moving it around, throwing things out (rows). You can rearrange furniture every day without touching the walls, but knocking down a wall (DROP) takes the furniture with it.

Analogy: Mom's kitchen

The kitchen has rules about who may use it and what they may touch. That's DCL: GRANT gives someone access, REVOKE takes it back. And while cooking, nothing is final until the dish is served. That's TCL: COMMIT serves the dish, ROLLBACK throws away the attempt and starts over.
FamilyFull formWorks onCommands
DDLData Definition LanguageStructure (schema)CREATE, ALTER, DROP, TRUNCATE, RENAME
DMLData Manipulation LanguageData (rows)INSERT, UPDATE, DELETE (and SELECT)
DCLData Control LanguagePermissionsGRANT, REVOKE

➕ Added for exam
  • Many books list a fifth family, DQL (Data Query Language), containing only SELECT. Others put SELECT under DML. If DQL is an option, choose it for SELECT.
  • SQL was developed at IBM (as SEQUEL, for System R) in the 1970s and became an ANSI standard in 1986.
⚠️ Exam trap TRUNCATE is DDL, not DML, even though it removes rows. DELETE is DML. This is the most-asked classification question in SQL.

12.2CREATE DATABASE, CREATE TABLE and Data Types (CHAR vs VARCHAR)

🎓 Lecture topic (from outline)

Create the plot, then the house

CREATE DATABASE College;
USE College;
CREATE TABLE Student (
  Roll INT PRIMARY KEY,
  Name VARCHAR(50) NOT NULL,
  Gender CHAR(1),
  City VARCHAR(30) DEFAULT 'Delhi',
  Marks DECIMAL(5,2) CHECK (Marks BETWEEN 0 AND 100),
  DOB DATE
);
Each column gets a name, a data type and optional constraints.

🎓 Lecture topic (from outline)

CHAR vs VARCHAR

Store 'Ram' in both CHAR(10) and VARCHAR(10):
  • CHAR(10) always uses 10 characters: 'Ram' plus 7 padding spaces. Space is wasted, but every value is the same size, so access is slightly faster.
  • VARCHAR(10) uses 3 characters, plus a small length marker (1–2 bytes). Nothing is wasted.
Use CHAR when every value has the same length (gender, PIN code, state code); VARCHAR when lengths vary (names, addresses).
➕ Added for exam
  • Oracle's name for VARCHAR is VARCHAR2. Its NUMBER(p, s) plays the role of DECIMAL.
  • The maximum CHAR length is usually 255 (MySQL) or 2000 bytes (Oracle); VARCHAR goes much higher.
  • Text and date values go in single quotes: 'Delhi', '2026-10-27'.

12.3ALTER, RENAME, DROP and TRUNCATE

🎓 Lecture topic (from outline)

ALTER TABLE: change the structure

  • Add a column: ALTER TABLE Student ADD Phone VARCHAR(15);
  • Change a column's type: ALTER TABLE Student MODIFY Name VARCHAR(80); (MySQL, Oracle; SQL Server uses ALTER COLUMN)
  • Remove a column: ALTER TABLE Student DROP COLUMN Phone;
  • Rename a column: ALTER TABLE Student RENAME COLUMN City TO HomeCity;
  • Add a constraint later: ALTER TABLE Student ADD CONSTRAINT uq_name UNIQUE (Name);

RENAME: change a table's name

RENAME TABLE Student TO Pupil; (MySQL), RENAME Student TO Pupil; (Oracle), or the portable ALTER TABLE Student RENAME TO Pupil;

TRUNCATE: empty the house, keep the walls

TRUNCATE TABLE Student; removes all rows at once. The table, its columns and constraints remain. No WHERE clause is allowed.

DROP: knock the house down

DROP TABLE Student; removes the rows and the table itself: its structure, indexes, constraints and permissions. DROP DATABASE College; removes the whole database.
⚠️ Exam trap ALTER changes the structure; UPDATE (DML) changes the data. "Increase every salary by 10%" is UPDATE, not ALTER. "Add a Salary column" is ALTER.

12.4Foreign Key Syntax, INSERT and DELETE

🎓 Lecture topic (from outline)

Foreign key (chapter 4.3 in SQL)

CREATE TABLE Enrol (
  Roll INT,
  Course VARCHAR(10),
  PRIMARY KEY (Roll, Course),
  FOREIGN KEY (Roll) REFERENCES Student(Roll)
    ON DELETE CASCADE ON UPDATE CASCADE
);
Enrol is the referencing (child) table; Student is the referenced (parent) table. The ON DELETE / ON UPDATE options decide what happens to child rows when the parent row changes (chapter 4.4):
  • CASCADE: delete or update the child rows too.
  • SET NULL: set the child's foreign key to NULL.
  • RESTRICT / NO ACTION (the default): refuse to delete the parent while children exist.

INSERT: add rows

  • All columns, in table order: INSERT INTO Student VALUES (1, 'Asha', 'F', 'Pune', 82.5, '2004-05-10');
  • Named columns (others get DEFAULT or NULL): INSERT INTO Student (Roll, Name) VALUES (2, 'Ravi'); — City becomes 'Delhi' from the DEFAULT.
  • Several rows at once: INSERT INTO Enrol VALUES (1, 'DBMS'), (1, 'OS'), (2, 'DBMS');
  • Copy rows from a query: INSERT INTO Alumni SELECT * FROM Student WHERE Marks > 90;

DELETE: remove rows

  • Some rows: DELETE FROM Student WHERE Roll = 2;
  • All rows (table stays): DELETE FROM Student;
➕ Added for exam: UPDATE UPDATE Student SET Marks = Marks + 5, City = 'Mumbai' WHERE Roll = 1; Leaving out WHERE updates every row, the most common real-world SQL accident.
⚠️ Exam trap Inserting into Enrol a Roll that doesn't exist in Student fails (referential integrity). Deleting a Student who has Enrol rows fails too, unless the foreign key says ON DELETE CASCADE or SET NULL.

12.5GRANT/REVOKE and COMMIT/ROLLBACK

🎓 Lecture topic (from outline)

DCL: who may do what

  • GRANT SELECT, INSERT ON Student TO ravi; — Ravi may read and add rows.
  • GRANT ALL PRIVILEGES ON Student TO admin1;
  • GRANT SELECT ON Student TO ravi WITH GRANT OPTION; — Ravi may pass the permission on to others.
  • REVOKE INSERT ON Student FROM ravi; — take it back.

TCL: making changes final

  • COMMIT makes every change since the last commit permanent.
  • ROLLBACK undoes every change since the last commit.
  • SAVEPOINT s1 marks a point inside a transaction; ROLLBACK TO s1 undoes only the changes after it.
StepCommandRows in Student afterwards
1INSERT Roll 1; COMMIT;{1} (permanent)
2INSERT Roll 2;{1, 2}
3SAVEPOINT s1;{1, 2}
4INSERT Roll 3;{1, 2, 3}
5ROLLBACK TO s1;{1, 2}: Roll 3 undone
6ROLLBACK;{1}: back to the last COMMIT
⚠️ Exam trap In Oracle and MySQL, every DDL statement commits automatically (an implicit COMMIT before and after it). So after INSERT …; CREATE TABLE …; ROLLBACK; the INSERT is not undone; the CREATE already committed it. For the same reason, TRUNCATE and DROP can't be rolled back there.

🎯 IBPS exam alert The SQL questions that come up most: classify a command (DDL / DML / DCL / TCL), DELETE vs TRUNCATE vs DROP, CHAR vs VARCHAR, PRIMARY KEY vs UNIQUE (one per table vs many; NULL not allowed vs allowed), and what ROLLBACK undoes after a SAVEPOINT.

12.7Solved Exam QuestionsADDED

Q1Which is a DDL command? (a) INSERT (b) UPDATE (c) TRUNCATE (d) GRANT
Answer: (c) TRUNCATE. INSERT and UPDATE are DML; GRANT is DCL.
Q2Which command removes a table's rows and its structure?
Answer: DROP TABLE.
Q3A column of type CHAR(8) stores 'SQL'. How many characters does it occupy?
Answer: 8 (padded with 5 spaces). VARCHAR(8) would use 3.
Q4Which command can delete specific rows using a condition? (a) DROP (b) TRUNCATE (c) DELETE (d) ALTER
Answer: (c) DELETE.
Q5Which command adds a new column to an existing table?
Answer: ALTER TABLE … ADD.
Q6COMMIT and ROLLBACK belong to:
Answer: TCL (Transaction Control Language).
Q7Which clause lets a user pass a privilege on to other users?
Answer: WITH GRANT OPTION.
Q8DECIMAL(6, 2) can hold a maximum value of:
Answer: 9999.99 (6 digits in total, 2 after the point).

⚡ Rapid Revision

  • DDL (structure): CREATE, ALTER, DROP, TRUNCATE, RENAME. Builds the house on the empty plot.
  • DML (data): INSERT, UPDATE, DELETE (+ SELECT, or DQL). Living in the house.
  • DCL: GRANT, REVOKE. Who may use Mom's kitchen. TCL: COMMIT, ROLLBACK, SAVEPOINT.
  • CHAR(n) fixed length, padded; VARCHAR(n) variable length, no padding. DECIMAL(p, s) = p digits, s after the point.
  • ALTER ADD / MODIFY / DROP COLUMN / RENAME COLUMN changes structure; UPDATE changes data.
  • TRUNCATE = all rows, keeps table, no WHERE, DDL. DROP = rows + structure. DELETE = DML, WHERE allowed, can roll back.
  • FK: FOREIGN KEY (Roll) REFERENCES Student(Roll) ON DELETE CASCADE / SET NULL / RESTRICT.
  • INSERT INTO … VALUES (…); named columns get the rest as DEFAULT/NULL. DELETE FROM … WHERE …; no WHERE = all rows.
  • GRANT … ON … TO … [WITH GRANT OPTION]; REVOKE … ON … FROM …
  • ROLLBACK TO savepoint undoes only later changes; ROLLBACK undoes to the last COMMIT. ➕ DDL auto-commits in Oracle/MySQL.
