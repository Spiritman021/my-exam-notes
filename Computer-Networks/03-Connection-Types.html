Chapter 3

Connection Types (Line Configuration)

Chapter 2 covered the direction of data flow. Before looking at how many devices are arranged (topologies, Chapter 4), we need the most basic question: is a link dedicated to two devices, or shared by many?

3.0What is Line Configuration?

Line configuration (type of connection): the way two or more devices are attached to a link. A link is the physical communication pathway that carries data from one device to another. For communication to happen, devices must be connected to the same link at the same time. There are two types: point-to-point and multipoint.

3.1Point-to-Point vs Multipoint Connection

🎓 From the lecture
  • Point-to-point: a direct, dedicated link between two devices, D1 and D2. All communication and data exchange between them happens through this one link, which belongs only to them.
  • Multipoint: one link to which more than two devices (D1, D2, D3…) are connected. It is a shared link / shared channel, not a dedicated one, between two or more devices.

3.1AComparison, Examples & Sharing Types ADDED

BasisPoint-to-pointMultipoint (multidrop)
LinkDedicated to exactly two devicesShared by more than two devices
CapacityWhole capacity reserved for the pairCapacity shared, spatially or by time
AddressingNot needed: there is only one receiverNeeded: frames must carry the destination address
Collisions / access controlNonePossible, so a multiple-access protocol is needed (Chapter 12)
Security / privacyHigherLower (others on the line can listen)
CostMore links for many devicesFewer cables, cheaper
TopologiesPoint-to-point, mesh, the device-to-hub links of a star, ringBus; shared wireless channel
ExamplesTV ↔ remote (infrared), leased line between bank branches, PPP dial-up, a cable from PC to switch, satellite link pairOld bus Ethernet (coaxial), Wi-Fi channel, mainframe with many terminals on one line, cable TV
  • Spatially shared: several devices use the link at the same time, each with part of the capacity (e.g. frequency division).
  • Temporally shared (time-shared): devices take turns using the whole link (e.g. time division, polling).
  • In multipoint lines with a controller, one station is the primary (it polls and selects) and the others are secondaries, as in HDLC's normal response mode and old mainframe networks.
🎯 IBPS exam alert "A link shared by more than two devices" → multipoint. "TV remote control uses?" → a point-to-point connection (and simplex mode). PPP (Point-to-Point Protocol) is the data-link protocol for point-to-point links such as dial-up and DSL.

⚡ Rapid Revision — Chapter 3

  • Line configuration = how devices attach to a link. Two types.
  • Point-to-point: a dedicated link between exactly 2 devices (D1 ↔ D2); full capacity, no addressing or collisions. Remote control, leased line, PPP; mesh topology.
  • Multipoint: one shared link/channel for 3+ devices; needs addressing and access control (CSMA etc.). Bus topology, Wi-Fi, mainframe terminals.
  • Sharing can be spatial (simultaneous) or temporal (time-shared, turns); primary/secondary stations do the polling.
