Chapter 16

MAC Address

In chapter 15 the Ethernet frame carried a 6-byte destination and a 6-byte source address. This chapter is about those addresses. A MAC address identifies a network interface on the local link. It is fixed by the manufacturer, written as 12 hex digits, and a single bit in its first byte tells whether a frame is meant for one station or for a group.

16.0What is a MAC Address?

🎓 From the lecture We are discussing the data link layer, and leaving out the MAC address would be "badi galat baat". MAC = Media Access Control address, lovingly called the physical address. In the next layer (network layer) comes the IP address, the logical address. Later there is a full "MAC vs IP" contest over many rounds; for now, learn where the MAC address is found and how it is written.
MAC address: a 48-bit (6-byte) identifier assigned to a network interface card (NIC), used by the data link layer (MAC sublayer) to deliver frames within one local network (hop to hop). Also called the physical, hardware, Ethernet or burned-in address (BIA).

16.1MAC Address Location and Format (NIC, 48-bit Hex)

🎓 From the lecture Every device you buy comes with a Network Interface Card (NIC). On it is a ROM, and the MAC address is written there in a hard-coded way.
It is written with a colon (:) or a dash (-) as the separator; each group between separators is one byte. Why one byte? Hexadecimal digits run 0–9 then A–F (10–15): 16 = 2⁴ options, so one hex digit = 4 bits, and two hex digits = 8 bits = 1 byte. Six such groups = 6 bytes = 6 × 8 = 48 bits.
➕ Quick facts 12 hex digits, 48 bits → 2⁴⁸ ≈ 281 trillion possible addresses. A third notation (Cisco) groups 4 hex digits with dots: A24F.1C7B.3D90. To see yours: Windows ipconfig /all or getmac; Linux/macOS ip link / ifconfig. The 48-bit format is called EUI-48 (IEEE); IPv6 uses a 64-bit form, EUI-64.

16.2OUI (Manufacturer ID) and Device ID; Burned-In Address

🎓 From the lecture The first 3 bytes tell us about the NIC manufacturer. The last 3 bytes are the device ID.
Unlike the IP address (which is flexible, as we will see), the MAC address is treated as permanent. That is why it is called a burned-in address: it has been "burned" into the card and cannot be changed.
➕ Who assigns what The first 24 bits are the OUI (Organizationally Unique Identifier), bought from the IEEE Registration Authority by each manufacturer (e.g. different OUIs for Intel, Cisco, Apple). The manufacturer then gives every card it makes a unique last-24-bit number. OUI + serial = globally unique. One OUI gives 2²⁴ ≈ 16.7 million addresses.
⚠️ Exam trap "Burned in and cannot be changed" is true of the address in the ROM. But the address the OS uses can be overridden in software: MAC spoofing / a locally administered address. Phones and laptops now use random MAC addresses per Wi-Fi network for privacy. If asked "can a MAC address be changed?", the textbook answer is "the burned-in one is fixed, but it can be spoofed in software".

16.3Unicast MAC Address

🎓 From the lecture Unicast = one-to-one: one station sends to exactly one other station.
Identification: look at the first byte and its LSB (least significant, right-most bit). Example first byte A2: A = 10 = 1010, 2 = 0010 → 1010 0010. The LSB is 0, so it is a unicast address.
Shortcut You only need the second hex digit of the first byte. If it is even (0, 2, 4, 6, 8, A, C, E), the LSB is 0 → unicast. If it is odd (1, 3, 5, 7, 9, B, D, F), the LSB is 1 → multicast.

16.4Multicast MAC Address

🎓 From the lecture Multicast = one-to-many. The festival-wishes analogy: sending a wishes picture to each relative one by one is time-consuming, so you make a group (close relatives, close friends) and post the message once; everyone in the group gets it.
Likewise station D wants to send to A, B and C only. Put A, B, C in a group; the group gets a group ID, and that group ID is the multicast address. Send to it once, and A, B and C all receive it.
Identification: first byte A1 = 1010 0001. The LSB is now 1, so it is a multicast address.
➕ Real multicast MACs IPv4 multicast maps to MACs starting 01:00:5E; IPv6 multicast to 33:33. Spanning Tree (STP) BPDUs go to 01:80:C2:00:00:00. All start with an odd second digit, as the rule predicts. A multicast address can only be a destination, never a source.

16.5Broadcast MAC Address

🎓 From the lecture Broadcast is different from multicast. On the bus there may be many more nodes; multicast reached only the chosen group (A, B, C). Broadcast means, literally, from one to everyone (recall the broadcast domain from the network-devices chapter).
The broadcast MAC address is all Fs: two Fs per byte × 6 bytes = 12 Fs → FF:FF:FF:FF:FF:FF. Remember "12 F".
🎯 IBPS exam alert FF:FF:FF:FF:FF:FF = all 48 bits set to 1. It is used by ARP requests ("who has this IP?", chapter 24) and DHCP Discover. Switches flood broadcast frames out of every port; routers do not forward them, so a router marks the edge of a broadcast domain.

16.6Broadcast vs Multicast Addresses

🎓 From the lecture The golden statement: every broadcast address is a multicast address, but the reverse is not true. Picture broadcast as a circle inside the bigger multicast circle. The first byte of the broadcast address is FF; its LSB is 1, so it satisfies the multicast rule. But A1:… is multicast (LSB 1) and not broadcast, because it is not 12 Fs.

16.7The Second Bit, Transmission Order and Special Addresses ADDED

Two flag bits in the first byte: bit 0 (LSB) = I/G (Individual/Group): 0 = unicast, 1 = multicast. Bit 1 = U/L (Universal/Local): 0 = globally unique (assigned via the IEEE OUI), 1 = locally administered (set by an admin or software; random MACs use this).
Read the first byte
first byte b7 b6 b5 b4 b3 b2 | b1 | b0 | U/L | I/G A2 = 1010 0010 → U/L = 1 (local), I/G = 0 (unicast) A0 = 1010 0000 → U/L = 0 (global), I/G = 0 (unicast) 01 = 0000 0001 → U/L = 0 (global), I/G = 1 (multicast)
➕ Transmission order Ethernet sends each byte LSB first (left to right byte by byte, but within a byte from right to left). So the I/G bit is the very first bit of the destination address on the wire: a station knows at once whether the frame is individual or group. Example: 47 = 0100 0111 is sent as 11100010.

Solved questions Q1. Type of 4A:30:10:21:10:1A? First byte 4A, second digit A (even) → unicast.

Q2. Type of 47:20:1B:2E:08:EE? Second digit 7 (odd) → multicast.

Q3. Type of FF:FF:FF:FF:FF:FF? Broadcast (and, technically, multicast too).

Q4. How many hex digits and bits in a MAC address? 12 hex digits, 48 bits.

Q5. Which part identifies the vendor? The first 24 bits (OUI).

Q6. Which device uses MAC addresses to forward frames? A switch / bridge (layer 2). A router uses IP addresses.

⚡ Rapid Revision — Chapter 16

  • MAC = Media Access Control = physical address (IP = logical). Layer 2, used for hop-to-hop delivery.
  • Stored hard-coded in the NIC's ROM → burned-in address, permanent (but can be spoofed in software).
  • 48 bits = 6 bytes = 12 hex digits; separators : or -. 1 hex digit = 4 bits; 2 hex digits = 1 byte.
  • First 3 bytes = OUI / manufacturer (from IEEE); last 3 bytes = device ID.
  • Unicast (1→1): LSB of first byte = 0 (A2 = 1010 0010). Multicast (1→group, festival WhatsApp group): LSB = 1 (A1 = 1010 0001). Shortcut: 2nd hex digit even = unicast, odd = multicast.
  • Broadcast (1→all): 12 Fs, FF:FF:FF:FF:FF:FF. Used by ARP; switches flood it, routers block it.
  • Golden rule: every broadcast is multicast; not every multicast is broadcast.
  • Bit 1 of the first byte = U/L (0 global, 1 local). Ethernet sends LSB first, so the I/G bit goes out first.
