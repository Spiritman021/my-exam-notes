Chapter 6

Circular Linked List

Take a singly linked list, and instead of storing NULL in the last node, store the address of the first node. The chain becomes a ring. You can start anywhere and reach every node, but you can also loop forever if you test for NULL out of habit. The lecture admits this variation draws fewer questions than singly and doubly lists, but "it is a part", and its few questions are predictable.

6.1Concept: Last Node Points to Head

🎓 From the lecture The lecture uses a singly circular linked list: the nodes look exactly like singly-linked-list nodes, but the behaviour is circular.
In one line: last->next = head. The last node's next pointer points back to the head node.
So far the last node held NULL to say "this is the end". Here it comes round again: it is a chakravyuh, a never-ending round, with no end.
Circular linked list: a linked list in which the last node points back to the first node instead of NULL, so there is no NULL link and every node is reachable from every other node.
➕ Added for exam There are two kinds:
  • Circular singly: last→next = first.
  • Circular doubly: additionally first→prev = last (6.4).
A one-node circular list points to itself (head->next == head). An empty one is still head == NULL.

6.2Deleting the Head Node

🎓 From the lecture As an example operation, delete the starting (head) node and make the second node the new head. "The other operations you can do the same way."
  1. Reach the last node. Set current = head, then loop while (current->next != head), moving with current = current->next.
    • Look carefully at the condition: in traversals we usually tested for NULL, but here it is head.
    • The node whose next is head can only be the last node; that is the characteristic of a circular list.
  2. temp = head; Temp points to the starting node.
  3. head = head->next; The second node becomes the new head.
  4. current->next = head; We walked to the last node precisely because its next pointer must now point to the new head. That makes "a lovely circular list" again, and the old first node is left out.
  5. free(temp); Free the node that temp has pointed to since step 2.
Everything else works like a singly linked list; you just have to be careful with the last node's pointer.
struct node *current = head, *temp; while (current->next != head) /* stop at last node */ current = current->next; temp = head; head = head->next; current->next = head; /* close the ring again */ free(temp);
⚠️ Exam trap
  • The lecture says step 3 aloud as "head next = head"; the assignment is head = head->next.
  • Deleting the head of a circular list is O(n), not O(1) as in a singly list, because the last node must be found to re-close the ring.
  • Single node: the loop stops at once (current = head), then head = head->next is the same node, which then gets freed, leaving head dangling. Handle it separately: if (head->next == head) { free(head); head = NULL; }.

6.3Traversal, Insertion & the Last-Pointer TrickADDED

Traversal. There is no NULL to stop at, so stop when you are back at head. Use a do-while loop, so that the first node is printed before the check:

if (head != NULL) { struct node *p = head; do { printf("%d ", p->data); p = p->next; } while (p != head); }
⚠️ Exam trap
  • while (p != NULL) on a circular list is an infinite loop: p is never NULL.
  • p = head; while (p != head) runs zero times, because the condition is false at the start. That is why do-while is used.

The last-pointer trick. Many textbooks keep a pointer to the last node instead of head. Since last->next is the first node, one pointer gives both ends in O(1):

➕ Added for exam Insert at beginning and insert at end are the same pointer surgery in a circular list. The only difference is whether you then move last to the new node. This is why a circular list with a last pointer makes an efficient queue: enqueue at last, dequeue from last→next, both O(1), with a single pointer.

6.4Circular Doubly List, Applications, Comparison & Solved QuestionsADDED

➕ Circular doubly linked list Each node has prev and next. Additionally last->next = head and head->prev = last. From head you reach the last node in O(1) (head->prev), so insert and delete at both ends are O(1) with just a head pointer. It is used for deques, and for the doubly linked lists inside many OS kernels and libraries.

➕ Applications
  • Round-robin CPU scheduling: the ready queue is a ring, and each process gets a time slice in turn (OS chapter).
  • Multiplayer turns (board/card games), and repeating playlists.
  • Circular buffers (I/O, keyboard buffers, streaming).
  • The Josephus problem: n people stand in a circle and every k-th one is eliminated.
  • The Fibonacci heap keeps its root list as a circular doubly linked list.
🎯 IBPS exam alert
  • "In a circular linked list, the last node contains…" → the address of the first node (not NULL).
  • "Which list has no NULL pointer?" → circular linked list (a non-empty one).
  • "Which data structure suits round-robin scheduling?" → circular linked list / circular queue.
  • "Advantage of a circular list?" → any node can be the starting point, and you reach the first node from the last in one step.
  • "Danger of a circular list?" → infinite loop if the end condition is wrong.
Q1Pointer p is at some node of a circular singly list. Which condition tells you that p is the last node? → p->next == head.
Q2A circular singly list is accessed only through a pointer to its last node. Which takes O(n)? (a) insert at front (b) insert at end (c) delete front (d) delete last → (d): the second-last node needs a full walk.
Q3Josephus: 5 people in a circle (1–5), every 2nd person is eliminated, starting the count from person 1. Who survives? → The order out is 2, 4, 1, 5, so 3 survives. (Recurrence: J(n) = (J(n−1) + k) mod n, with J(1) = 0, 0-indexed.)
Q4Same with 7 people and k = 3? → The order out is 3, 6, 2, 7, 5, 1, so 4 survives.
Q5Why does the lecture's delete-head code first walk to the last node? → In a circular list the last node's next must be updated to the new head; without it the ring would still point to the freed node, a dangling pointer.

⚡ Rapid Revision

  • Circular list = singly nodes with last→next = head. There is no NULL and no end: the lecture's "chakravyuh".
  • Find the last node with while (cur→next != head), testing for head, not NULL.
  • Delete head (lecture): walk cur to last; temp = head; head = head→next; cur→next = head; free(temp). O(n); a single node is a special case.
  • Traverse with do-while (while (p != head)). while (p != NULL) loops forever.
  • Keep a last pointer: last→next is the first node, so insert at front/end and delete front are O(1). Delete last is still O(n) in a singly circular list.
  • Circular doubly: head→prev = last, so both ends are O(1).
  • Uses: round-robin scheduling, game turns, playlists, circular buffers, Josephus (n=5, k=2 → 3; n=7, k=3 → 4).
