Chapter 16

Graphs

A tree is a graph with strict rules: one root, one parent per node, no cycles. A graph drops those rules. Any vertex may connect to any other, so a road map, a social network or a computer network fits naturally. With that freedom come cycles, which is why graph traversal must remember which vertices it has already visited.

16.1Introduction: Nodes (Vertices), Edges and Cycles

🎓 From the lecture A graph also has nodes, but with one special feature: cycles (loops) can form among them. It is a non-linear data structure made of:
  • nodes, also called vertices (n1, n2, …);
  • edges, which connect the vertices. They are also called lines or arcs.
The edges among the nodes can form a circle, a cycle. The key topics ahead are DFS and BFS.
Graph G = (V, E): a set V of vertices and a set E of edges, where each edge joins a pair of vertices. |V| = n vertices, |E| = e edges.

16.2Types of Graphs

🎓 From the lecture
  • Directed graph: the edge has a direction; it goes from 1 to 2. Use it when the direction matters.
  • Undirected graph: no direction. You can say 1 is connected to 2 or 2 to 1; it works both ways.
  • Weighted graph: each edge carries a weight (cost or distance). It is very significant in algorithms that find the shortest path or the least cost.
  • Unweighted graph: no weights, like the plain undirected example.
  • Complete graph: every pair of vertices has an edge. Each vertex is connected to all the others.
  • Simple graph: at most one edge between any pair of vertices.
  • Multigraph: the opposite. There can be more than one edge between the same pair (e1, e2).
  • Null graph: only vertices, number of edges = 0. The vertices sit disjoint in space.
➕ Added for exam
  • A self-loop is an edge from a vertex to itself. A simple graph has no self-loops and no parallel edges.
  • Connected: there is a path between every pair of vertices. In a directed graph, strongly connected means there is a directed path both ways between every pair.
  • Cyclic vs acyclic: a directed acyclic graph is a DAG (used in scheduling and compilers).
  • A tree is a connected, acyclic, undirected graph with exactly n − 1 edges.

16.3Adjacency Matrix (Undirected and Directed)

🎓 From the lecture Questions are asked on representing a graph as an adjacency matrix or an adjacency list. The matrix looks like the 2-D array seen earlier.
  • The graph has 4 vertices and 4 edges, so the matrix is always V × V, here 4 × 4. Label the rows and columns 0, 1, 2, 3.
  • Wherever an edge exists, write 1; a blank or 0 means no edge.
  • Undirected: count both ways. 0–1 gives a 1 at [0][1] and [1][0].
    • 1 is connected to 0, 2 and 3;
    • 2 to 1 and 3;
    • 3 to 1 and 2;
    • 2 and 0 are not connected, so that cell is blank.
  • Directed: more selective. There is a 1 only from the source row to the destination column.
    • 0 → 1 sets [0][1], but not [1][0];
    • 1 → 2, 1 → 3 and 2 → 3 set their own cells;
    • 3 has no outgoing edge, so its row is all empty.

➕ Added for exam
  • The matrix of an undirected graph is symmetric (A[i][j] = A[j][i]), and the number of 1s = 2e. Here 8 ones for 4 edges.
  • For a directed graph, the number of 1s = e. Row sum = out-degree; column sum = in-degree.
  • For a weighted graph, store the weight instead of 1, and ∞ or 0 for "no edge".
  • Space O(V²), and checking whether edge (u, v) exists is O(1).

16.4Adjacency List (Avoiding the Sparse Matrix)

🎓 From the lecture Why is a second method needed? The matrix wastes a lot of space. It is often a sparse matrix: most entries are empty or 0, and only a few are filled.
Instead, make an array of the 4 vertices (0–3). From each one, hang a linked list of the vertices it connects to, ending in NULL:

➕ Added for exam In an undirected graph each edge appears twice in the lists, so there are 2e list nodes (8 here). In a directed graph each edge appears once. BFS and DFS cost O(V + E) with lists but O(V²) with a matrix.

16.5BFS (Breadth First Search) Using a Queue

🎓 From the lecture "The most important question": graph traversal, meaning visiting all the vertices in a certain fashion. BFS uses a queue and DFS uses a stack. Using these structures during the trace makes it very easy.
  • The queue starts empty. Insert the start vertex A.
  • Dequeue a vertex, write it into the BFS sequence, then enqueue all its neighbours that are not yet visited.
  • Neighbours already visited (or already in the queue) are not enqueued again. Example: when B leaves, A is already visited, so only C is added.
  • Repeat with whatever is at the front, until the queue is empty.

⚠️ Exam trap
  • When A leaves, all of its unvisited neighbours (B, D and E) go into the queue at once. The lecture says "B, D" there and brings E in later; with A–E as an edge, E must be enqueued in the first step.
  • BFS visits vertices level by level: distance 0 (A), distance 1 (B, D, E), distance 2 (C, F), distance 3 (G).
  • Neighbours are taken in alphabetical order here. A different order gives a different but equally valid BFS, so check the options for one that respects the levels.

16.6DFS (Depth First Search) Using a Stack

🎓 From the lecture "This method will give you the answer quickly every time."
  1. First write the neighbour list of every vertex: A: B, D, E; B: A, C, E; C: B, E, F, G; and so on. BFS needs it too.
  2. Keep a visited list and cross out each vertex as it is visited.
  3. Push A, then pop it and add it to the sequence. Push its neighbours B, D, E (in that order) and mark them.
  4. The top is E: pop it. Its unvisited neighbours are C and F, so push C, then F.
  5. Pop F. Its unvisited neighbour G is pushed. Pop G; everything is now visited.
  6. Now just pop, pop, pop: C, D, B.
"Don't forget to cross out what's already visited; I forgot for G just now, and that's how confusion creeps in."

⚠️ Exam trap DFS orders are not unique. The lecture's stack method (push all neighbours, take the top) gives A E F G C D B. The recursive DFS (go to the first unvisited neighbour immediately) on the same graph gives A B C E D F G. Both are correct DFS orders. In an MCQ, check whether each step really goes "as deep as possible" before backtracking.

16.7Degree, Edge Limits, Complexity, Spanning Trees & Solved QuestionsADDED

➕ Formulas
  • Degree of a vertex = the number of edges at it. In a directed graph, in-degree + out-degree.
  • Handshaking lemma: Σ degrees = 2e, so the number of odd-degree vertices is always even. For the lecture graph: 3 + 3 + 4 + 2 + 5 + 3 + 2 = 22 = 2 × 11 edges ✔.
  • Max edges in a simple undirected graph on n vertices = n(n − 1)/2, which is the complete graph Kₙ. Directed: n(n − 1).
  • Every vertex of Kₙ has degree n − 1.
  • A connected graph needs at least n − 1 edges. A tree has exactly n − 1.

➕ Spanning trees & shortest paths (one-liners)
  • A spanning tree of a connected graph uses all n vertices and n − 1 edges, with no cycle. Kₙ has nⁿ⁻² spanning trees (Cayley).
  • Minimum spanning tree: Kruskal's algorithm (sort edges, add the smallest that doesn't form a cycle) or Prim's (grow from a vertex).
  • Shortest path: BFS (unweighted), Dijkstra's (non-negative weights), Bellman-Ford (negative weights), Floyd-Warshall (all pairs).
  • Topological sort (DAG only): a linear order in which every edge goes forward, found with DFS or by repeatedly removing in-degree-0 vertices.
🎯 IBPS exam alert
  • BFS uses a queue; DFS uses a stack. Both run in O(V + E).
  • Adjacency matrix space O(V²); adjacency list O(V + E). Use a list for sparse graphs.
  • Max edges in an undirected simple graph = n(n−1)/2. Sum of degrees = 2e.
  • Graph with no edges = null graph; every pair connected = complete graph.
  • Applications: maps and GPS routes, networks and routing, social networks, dependency resolution, recommendation systems.
Q1Maximum edges in a simple undirected graph with 10 vertices? → 10 × 9 / 2 = 45.
Q2An undirected graph has degrees 3, 3, 2, 2, 2. How many edges? → Σ = 12, so e = 12 / 2 = 6.
Q3In the lecture graph, which vertices does BFS from A reach at distance 2? → C and F (G is at distance 3).
Q4A graph has 1,000 vertices and 3,000 edges. Matrix or list? → It is sparse (3,000 ≪ 499,500 possible), so use an adjacency list: about 7,000 entries (1,000 heads + 2 × 3,000 list nodes) vs 1,000,000 matrix cells.
Q5How many spanning trees does K₄ have? → 4⁴⁻² = 16.

⚡ Rapid Revision

  • Graph = vertices + edges (lines/arcs), non-linear, and cycles allowed.
  • Types: directed / undirected, weighted (cost, for shortest paths) / unweighted, complete (every pair joined), simple (≤ 1 edge per pair) vs multigraph (parallel edges), null (no edges).
  • Adjacency matrix: V × V, 1 = edge. Symmetric if undirected; for directed graphs row → column. O(V²) space, often sparse.
  • Adjacency list: array of vertices + a linked list of neighbours. O(V + E) space, better for sparse graphs.
  • BFS = queue: dequeue, visit, enqueue the unvisited neighbours. The lecture graph from A gives A B D E C F G.
  • DFS = stack: pop, visit, push the unvisited neighbours. The lecture's method gives A E F G C D B (recursive DFS gives A B C E D F G; both valid).
  • Σ degree = 2e. Max edges n(n−1)/2. Spanning tree has n − 1 edges; Kₙ has nⁿ⁻² of them.
