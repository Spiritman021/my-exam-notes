Chapter 10

Trees: Introduction and Terminology

🎓 From the lecture Now we come to the main and biggest data structure, on which there is a lot to discuss: the tree. It belongs to the non-linear category: data is arranged hierarchically, in multiple levels. It has many basic terms, and we go through them one by one on a single example tree.
Tree: a finite set of nodes with one special node, the root. The remaining nodes are split into disjoint subtrees, each of which is itself a tree. Every node except the root has exactly one parent, and there are no cycles.

10.1Root, Leaf, Parent, Child and Non-Leaf Nodes

🎓 From the lecture
  • Root: the top node, here A.
  • Leaf: a node with no children, the lowest nodes because nothing comes after them: D, E, G, H. F is not a leaf, because it has children.
  • Parent: a node whose children exist: A, B, C, F. A's children are B and C; B's are D and E; C's is F; F's are G and H.
  • Child: B and C are children of A; D and E of B; F of C; G and H of F.
  • Child vs leaf: a child can also be the parent of other children. B is a child of A and the parent of D and E. A leaf can never be a parent.
  • Non-leaf nodes: put a bar over the leaves; everything else is non-leaf: A, B, C, F.
➕ Added for exam Leaf = external node = terminal node. Non-leaf = internal node = non-terminal node. The root counts as an internal node whenever it has at least one child. A single-node tree's root is also a leaf.

10.2Path, Ancestor/Descendant, Sibling and Degree

🎓 From the lecture
  • Path: the sequence of nodes from a starting node to an end node.
    • A to H: A → C → F → H.
    • A to D: A → B → D.
    • A to E: A → B → E.
    • C to G: C → F → G.
  • Ancestor / descendant, on the path A → C → F → H:
    • the nodes before C are its ancestors, so A;
    • the nodes after C are its descendants, so F and H.
  • Siblings: "a blood relation", children of the same parent.
    • D and E are siblings, and so are B and C.
    • E and F are not siblings, because E is B's child and F is C's. "You can call them cousins, but not siblings."
  • Degree of a node: how many children it has.
    • A has degree 2, B has 2, and D has 0.
    • A leaf always has degree 0.
(When naming the descendants, the lecture says "F and A"; it means F and H, the nodes after C on the path.)

➕ Added for exam
  • A node's ancestors are all the nodes on the path from the root to it. C's descendants are all the nodes below it (F, G, H), not only those on one path.
  • Degree of a tree = the maximum degree of any node (here 2).
  • The length of a path is usually counted in edges: A → C → F → H has length 3.
  • In a tree there is exactly one path between any two nodes.

10.3Depth and Height

🎓 From the lecture
  • Depth of a node is measured from the root down to that node.
    • From A to G is 1, 2, 3 edges, so depth(G) = 3, and the same for H.
    • The smallest depth is the root's own: root to root is 0.
  • Height is the opposite: measured from the node down to a leaf, under one condition: the deepest leaf, so take the maximum.
    • From A, one leaf (D) gives 2 and another (G) gives 3, so height(A) = 3.
    • height(C) = 2, height(F) = 1, height(E) = 0 (it is a leaf).
  • Always remember: the root's depth is 0, and a leaf's height is 0.

⚠️ Exam trap
  • Height of the tree = height of the root = maximum depth of any node; here 3.
  • Depth looks up to the root (one fixed answer). Height looks down and takes the max over all leaves.
  • Some books count nodes instead of edges, so a single-node tree has height 1, not 0. Check the question's convention; if options look off by one, that's why.

➕ Formulas that are asked
  • A tree with n nodes has exactly n − 1 edges (every node except the root has one edge to its parent). Example: 8 nodes, 7 edges.
  • Sum of all node degrees = number of edges = n − 1. Example: 2+2+1+0+0+2+0+0 = 7.
  • Leaf count in a general tree, where ni is the number of nodes of degree i:
    leaves n₀ = 1 + Σ (i − 1)·nᵢ = 1 + n₂ + 2n₃ + 3n₄ + …
    Check: n₂ = 3 (A, B, F) and n₁ = 1 (C), so n₀ = 1 + 3 = 4 (D, E, G, H) ✔.
  • A k-ary tree in which every internal node has exactly k children (full k-ary), with i internal nodes, has (k − 1)i + 1 leaves and ki + 1 nodes.
➕ Tree vs graph & applications
  • A tree is a connected, acyclic graph. A graph may have cycles, several paths between nodes, and no root (chapter 16).
  • Uses: file systems and folders, organisation charts, the HTML DOM, compiler parse/expression trees (chapter 8), database indexes (B/B+ trees), routing, decision trees, heaps for priority queues (chapter 14).
  • A general tree (any number of children) can be stored as a binary tree using the left-child, right-sibling representation.
🎯 IBPS exam alert
  • "A node with no children" → leaf / terminal / external node.
  • "Nodes with the same parent" → siblings.
  • "Number of edges in a tree of n nodes" → n − 1.
  • "Depth of the root" → 0. "Height of a leaf" → 0.
  • "Tree is a ____ data structure" → non-linear, hierarchical.
Q1In the lecture tree, list the ancestors of G and the descendants of B. → Ancestors of G: F, C, A. Descendants of B: D, E.
Q2A tree has 4 nodes of degree 3, 3 nodes of degree 2, 2 nodes of degree 1, and the rest are leaves. How many leaves? → n₀ = 1 + 2·4 + 1·3 + 0·2 = 12. Check: total nodes = 12 + 4 + 3 + 2 = 21, and edges = 4·3 + 3·2 + 2·1 = 20 = 21 − 1 ✔.
Q3A full 3-ary tree has 10 internal nodes. Leaves and total nodes? → Leaves = (3 − 1)·10 + 1 = 21; total = 3·10 + 1 = 31.
Q4A tree has 50 nodes. How many edges? → 49.
Q5Are E and F siblings in the lecture tree? → No. They have different parents (B and C); they are cousins.

⚡ Rapid Revision

  • Tree = non-linear, hierarchical, with multiple levels. The example is A(B(D, E), C(F(G, H))).
  • Root A. Leaves D, E, G, H (no children, degree 0). Parents / non-leaf: A, B, C, F. A child can be a parent; a leaf can't.
  • Path A→H = A, C, F, H. Ancestors come before a node on its root path; descendants come after it. Siblings share a parent (E and F are cousins).
  • Degree = number of children. Degree of the tree = the maximum degree.
  • Depth = root → node (root 0). Height = node → deepest leaf (leaf 0). Height of the tree = height of the root = 3.
  • n nodes ⇒ n − 1 edges. Leaves n₀ = 1 + Σ(i − 1)nᵢ. A full k-ary tree with i internal nodes has (k−1)i + 1 leaves.
